Introduction
          In today’s world, businesses use data analysis to understand sales performance and customer behavior. Sales data helps companies know which products sell more and generate higher revenue.
In this project, we analyzed sales data using Python libraries – Pandas and NumPy.Pandas was used to load and organize the dataset, and NumPy was used to perform mathematical and statistical calculations.
The main aim of this project is to calculate total sales, average sales, and analyze product performance using array operations.

Dataset Overview

The dataset contains information about electronic products. The main columns used are:

Product Name

Unit Price

Quantity Sold

Rating

From these values, we calculated:

Revenue (Unit Price × Quantity)

Estimated Profit

The dataset was imported from Google Drive into Google Colab using Pandas.

Methodology

The following steps were followed:

Imported the dataset using pandas.read_csv().

Checked the column names and values.

Converted important columns into NumPy arrays.

Used broadcasting to calculate revenue.

Applied statistical functions like:

Sum

Mean

Median

Variance

Standard Deviation

Identified the product with the highest revenue.

This method helped in analyzing data quickly and efficiently.

Statistical Analysis

Using NumPy functions:

Total Sales shows overall revenue.

Average Sales shows average product performance.

Median shows the middle value.

Standard Deviation shows variation in sales.

The analysis showed that some products generate much higher revenue than others. Products with good ratings also perform well in sales.

Conclusion

This project shows how NumPy and Pandas help in analyzing sales data easily.

Pandas helps in handling and organizing data.

NumPy helps in fast mathematical calculations.

Broadcasting makes revenue calculation simple.

Statistical analysis helps understand business performance.

Overall, data analysis is very important for making better business decisions.
